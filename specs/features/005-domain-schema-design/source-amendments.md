## A01 — AGENTS.md

Path: `AGENTS.md`, “Non-negotiable rules”, bullet beginning “Every protected resource requires server-side authentication, organization scope, object ownership and role evaluation.”

Proposed replacement:

> Every protected resource requires server-side authentication and explicit resource-specific authorization. Personal account resources require current account/session status, owner checks and applicable personal roles. Organizational resources additionally require explicit active organization, membership role, district grants and object relationship/ownership checks; ownership alone does not bypass organization scope. Global account-security actions require a separately approved named capability and narrowly scoped actor/target policy; neither an organization role nor NULL organization grants global authority. Apply these rules to REST, Socket.IO authorization and sensitive publication, with metadata-safe audit for high-impact actions.

Decision basis: C-11, D-S01/02/03/05/12/15/18; related D-002/003/004/012. Review: supervisor, independent security, product/backend and agent-instruction owner. Expected tests: AT-004/027, SEC-001, SC-35/36/39; no regressions in org/owner checks. **Blocked** until constitutional/security/P0 sign-off. Keep all forbidden-change/approval rules. Adjacent “currently specification-only; no implemented app exists” is stale: propose replacing only that sentence with “The backend foundation, PostgreSQL readiness and shutdown lifecycle are implemented; domain behavior remains proposed.” This factual correction needs tech-lead review; it does not grant implementation authority.
